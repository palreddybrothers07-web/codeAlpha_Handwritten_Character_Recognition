# Handwritten Character Recognition

## Project Overview

This project uses a Convolutional Neural Network (CNN) to recognize handwritten digits from 0 to 9.

## Technologies Used

* Python
* TensorFlow and Keras
* NumPy
* Matplotlib
* MNIST Dataset

## Project Workflow

1. Load the MNIST dataset.
2. Normalize the image pixel values.
3. Build a CNN model.
4. Train the model on handwritten digit images.
5. Evaluate the model using test data.
6. Predict digits from sample images.

## Results

The model's test accuracy is measured after training. See the notebook for the actual result.
